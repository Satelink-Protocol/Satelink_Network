# 11 — Machine-First + GEO Layer

§12. Everything generated from the live catalog + docs at build time — never
hand-typed. Builders live in `@satelink/seo`; contract schemas in
`@satelink/content`.

## Per product page
Visible **"For machines"** panel + machine-readable alternate:
- `/products/[slug].json` (schema `ProductJson`)
- `<link rel="alternate" type="application/json" href="/products/[slug].json">`

## Site-level machine endpoints
- `/pricing.json` (schema `PricingJson`) — generated from live catalog.
- `/.well-known/satelink.json` — proxy/redirect to `rpc.satelink.network` discovery.
- `/llms.txt` + `/llms-full.txt` — generated by `@satelink/seo` `generateLlmsTxt`/
  `generateLlmsFullTxt`. **Diff the existing static `/llms.txt` first; keep what's
  still true.** `llms-full.txt` concatenates canonical page bodies as Markdown.

## Per major page (GEO)
Answer-first intro (≤50 words defining the entity) · explicit terms · single H1 ·
logical H2/H3 · FAQ · author + published + modified dates · canonical · OG/Twitter.

## JSON-LD (via `@satelink/seo`)
- Sitewide: `Organization` + `WebSite` (SearchAction).
- Everywhere: `WebPage` + `BreadcrumbList`.
- Product pages: `Product`/`Offer` or `SoftwareApplication`.
- Content: `Article`/`NewsArticle`/`TechArticle`.
- `FAQPage` only where FAQs are visible; `HowTo` for tutorials.

## Validators (`seo:check`, CI-blocking)
Missing title/description/canonical · duplicate titles/descriptions/slugs/canonicals
· missing alt · invalid JSON-LD (schema-dts types + structured-data test) · orphan
pages · broken links · sitemap drift · **llms.txt freshness**. All composed from
`@satelink/seo/validators`.
