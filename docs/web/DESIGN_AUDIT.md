## Migration map (§5.4) — old token / literal → new `--sl-*` token

The new **Satelink Signal** system (`apps/web/src/styles/tokens.css`) is the single source of truth. Every legacy value below is codemodded to its target. The shadcn HSL set and the default oklch slate overrides are deleted; shadcn variable *names* still referenced by third-party components are aliased to the new tokens (see tokens.css `@layer base` alias block).

### Surfaces
| Legacy | New token |
| --- | --- |
| `--bg-base` | `--sl-bg` |
| `--bg-subtle` | `--sl-bg-raised` |
| `--bg-card`, `--bg-elevated`, `--bg-muted` | `--sl-surface` |
| `--bg-glass` | `--sl-bg-raised` + `backdrop-blur` (opacity via `/80`) |
| `--border` | `--sl-border` |
| `--border-subtle` | `--sl-border` (or `--sl-border-strong` where a divider needs weight) |

### Text
| Legacy | New token |
| --- | --- |
| `--text-primary` | `--sl-text` |
| `--text-secondary` | `--sl-text-muted` |
| `--text-muted` | `--sl-text-subtle` |

### Brand / accent
| Legacy | New token |
| --- | --- |
| `--accent`, `--primary`, `#5EEAD4` | `--sl-accent` |
| `--primary-hover` | `--sl-accent-strong` |
| `--accent-glow` | `--sl-accent-soft` |
| `#5c8374`, `#2D5A4A` (dark-teal gradient legs) | `--sl-accent-strong` or removed (no gradient-on-everything) |

### Data semantics
| Legacy | New token |
| --- | --- |
| `--success`, `#34D399` | `--sl-up` |
| `--error`, `#EF4444` | `--sl-down` |
| `--warning`, `#F59E0B` | `--sl-warn` |
| (model/proxy marker — new) | `--sl-model` (used ONLY on liquidation-clusters + modelled data) |

### Shape / type / motion
| Legacy | New token |
| --- | --- |
| `border-radius: 8px/10px/16px` ad-hoc | `--sl-radius-sm` / `--sl-radius` / `--sl-radius-lg` |
| `--font-sans` (Inter) | `--sl-font-sans` (Inter via next/font) |
| `--font-mono` (JetBrains) — was overused (16×) | `--sl-font-mono` — numbers/code/identifiers only |
| `--ease`, `--ease-out` | `--sl-ease` |

### Deleted outright
- `.theme-shadcn` oklch slate block (`--background: oklch(0.129 …)` etc.) — replaced by `--sl-*`; shadcn names aliased.
- macOS traffic-light dots `#FF5F56 / #FFBD2E / #27CA41` — kept ONLY as local constants inside `<TerminalWindow>` (on the §5.4 hex allowlist).
- Emoji feature icons — replaced with `lucide-react` (`<Icon>`).

### Hex allowlist (§5.4 gate)
`grep -rE '#[0-9a-fA-F]{3,8}\b' apps/web/src --include=*.tsx` must only match files matching: `TerminalWindow`, chart palette file (`chart`/`palette`), OG image (`og`/`opengraph`), `icon`. The truth-lint Vitest test enforces this.
